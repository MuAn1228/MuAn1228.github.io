提示

给你两个数 `hour` 和 `minutes` 。请你返回在时钟上，由给定时间的时针和分针组成的较小角的角度（60 单位制）。

示例 1：

<img src="/img/posts/af4a241d2ceb91b4911c02386192c530.png" width="226">
输入：hour = 12, minutes = 30
输出：165

示例 2：

<img src="/img/posts/4d4a2909575c88b4f6d23a7b0f5b3ccc.png" width="223">

输入：hour = 3, minutes = 30
输出；75

示例 3：

<img src="/img/posts/b61d0700deae7394a00011399e70eb81.png" width="222">

输入：hour = 3, minutes = 15
输出：7.5

示例 4：

输入：hour = 4, minutes = 50
输出：155

示例 5：

输入：hour = 12, minutes = 0
输出：0

提示：

- `1 <= hour <= 12`
- `0 <= minutes <= 59`
- 与标准答案误差在 `10^-5` 以内的结果都被视为正确结果。

# 题解：
```cpp
class Solution {
public:
    double angleClock(int hour, int minutes) {
        if(hour>=1 && hour<=11){
            double hour_du = hour30 + (minutes/60.0)30.0;
	        double min_du = minutes6;
	        double raw_diff = std::abs(hour_du - min_du);
	        double angle = std::min(raw_diff,360-raw_diff);
	        return angle;
        }else if(hour == 12){
            double hour_du =(minutes/60.0)30.0;
	        double min_du = minutes6;
	        double raw_diff = std::abs(hour_du - min_du);
	        double angle = std::min(raw_diff,360-raw_diff);
		    return angle;
        }
        return 0;
    }
};
```
