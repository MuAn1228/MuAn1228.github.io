#### 定义
除了泛型函数，Go 还支持泛型类型。类型可以通过类型参数进行参数化，这对于实现泛型数据结构非常有用。
```go
package main

// List represents a singly-linked list that holds
// values of any type.
type List[T any] struct {
	next *List[T]
	val  T
}

func main() {
}

```
本示例演示了一个简单的单链表类型声明，该单链表可以保存任何类型的值。
作为练习，请为这个列表实现添加一些功能。

#### 1. 泛型类型是什么？

之前你看到的 `Index[T comparable]` 是泛型函数——让函数处理多种类型。  
泛型类型则是让**类型本身**携带类型参数，使该类型能用于任意类型的值。

就像你可以说“一个装苹果的箱子”或“一个装书的箱子”，泛型类型 `List[T]` 就是“一个装 T 的箱子”，`T` 可以是任何类型。

---
#### 2. `List[T any]` 的定义拆解

```go
type List[T any] struct {
    next *List[T]
    val  T
}
```

`[T any]`：声明 `T` 是一个**类型参数**，`any` 是**约束**，意思是 **`T` 可以是任何类型**（`any` 是 `interface{}` 的别名）。
`next *List[T]`：指向**相同类型**的下一个节点（构成链表链）。
`val T`：当前节点存储的值，类型正是 `T`。

所以，`List` 不再是一个具体的类型，而是一个“类型生成器”：你需要指定 `T` 是什么，才会产生一个具体类型。例如：
`List[int]` 是存储整数的链表
`List[string]` 是存储字符串的链表

---
#### 3. `any` 约束是什么意思？

`any` 是一个预定义约束，等价于 `interface{}`，它**不限制任何东西**，所有类型都满足。  
所以 `List[T any]` 表示：**这个链表可以存放任意类型的值**。

---

#### 4. 为什么需要泛型类型？

如果没有泛型，你想实现一个整数链表，就得写：
```go
type IntList struct {
    next *IntList
    val  int
}
```

如果要一个字符串链表，又得写：

```go
type StringList struct {
    next *StringList
    val  string
}
```

代码重复，只是类型不同。泛型类型让你**只写一次，就能用于所有类型**，而且编译期保证类型安全。

---

#### 5. 练习要求

教程让你“给这个链表实现添加一些功能”，比如：

添加节点（`Add` 或 `Append`）
遍历打印（`Traverse`）
查找元素（`Find`）

例如，你可以定义一个方法 `Append`：

```go
func (l *List[T]) Append(v T) {
    // 找到尾节点，将新节点接上去
}
```

注意，方法的接收者也要带类型参数 `[T]`，但不需要重复写约束（因为类型定义里已经有了）。

---

添加一些功能后的代码：
```go
package main

import "fmt"

// List 表示一个单向链表，可以存储任意类型的值
type List[T any] struct {
	next *List[T]
	val  T
}

// NewList 创建一个带有初始值的新链表节点（工厂函数）
func NewList[T any](v T) *List[T] {
	return &List[T]{val: v}
}

// InsertAtHead 在链表头部插入一个新节点，返回新的头节点
func (l *List[T]) InsertAtHead(v T) *List[T] {
	newNode := &List[T]{val: v, next: l}
	return newNode
}

// Append 在链表尾部追加一个新值，返回头节点（方便链式调用）
// 如果链表为空，则返回新节点作为头节点
func (l *List[T]) Append(v T) *List[T] {
	if l == nil {
		return &List[T]{val: v}
	}
	current := l
	for current.next != nil {
		current = current.next
	}
	current.next = &List[T]{val: v}
	return l
}

// Find 查找第一个值等于 v 的节点，返回该节点指针；未找到返回 nil
func (l *List[T]) Find(v T, eq func(a, b T) bool) *List[T] {
	for p := l; p != nil; p = p.next {
		if eq(p.val, v) {
			return p
		}
	}
	return nil
}

// Traverse 遍历链表，对每个节点执行回调函数 f
func (l *List[T]) Traverse(f func(v T)) {
	for p := l; p != nil; p = p.next {
		f(p.val)
	}
}

// String 让链表以美观的方式打印（仅用于演示）
func (l *List[T]) String() string {
	if l == nil {
		return "[]"
	}
	result := "["
	for p := l; p != nil; p = p.next {
		result += fmt.Sprintf("%v", p.val)
		if p.next != nil {
			result += " -> "
		}
	}
	result += "]"
	return result
}

func main() {
	// 创建一个初始链表：头节点值为 1
	list := NewList(1)

	// 头部插入 0
	list = list.InsertAtHead(0)

	// 尾部追加 2, 3
	list = list.Append(2)
	list = list.Append(3)

	fmt.Println("链表内容:", list)

	// 遍历打印每个元素
	fmt.Print("遍历: ")
	list.Traverse(func(v int) {
		fmt.Printf("%d ", v)
	})
	fmt.Println()

	// 查找元素 2
	found := list.Find(2, func(a, b int) bool { return a == b })
	if found != nil {
		fmt.Println("找到元素:", found.val)
	} else {
		fmt.Println("未找到元素")
	}
}
```
