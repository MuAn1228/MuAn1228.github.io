#### 定义
此例源自A Tour Of Go——泛型——1/2——类型参数
Go 函数可以使用类型参数来处理多种数据类型。函数的类型参数位于函数参数之前，用方括号括起来。
```go
func Index [T comparable] (s []T, x T) int 
``` 
此声明表示 `s` 是满足内置约束 `comparable` 任意类型 `T` 的切片 `x` 也是相同类型的值。
`comparable` 是一个有用的约束，它使得可以使用 `==` 和 对类型值使用 `!=` 运算符。在本例中，我们用它来将一个值与所有切片元素进行比较，直到找到匹配项。此 `Index` 函数有效。 适用于任何支持比较的类型。
```go
package main

import "fmt"

// Index returns the index of x in s, or -1 if not found.
func Index[T comparable](s []T, x T) int {
	for i, v := range s {
		// v and x are type T, which has the comparable
		// constraint, so we can use == here.
		if v == x {
			return i
		}
	}
	return -1
}

func main() {
	// Index works on a slice of ints
	si := []int{10, 20, 15, -10}
	fmt.Println(Index(si, 15))

	// Index also works on a slice of strings
	ss := []string{"foo", "bar", "baz"}
	fmt.Println(Index(ss, "hello"))
}
```

**类型参数是理解Go 语言的泛型的基础**
教程中的示例代码用一个通用的查找函数 `Index` 演示了如何写出**能够安全地适用于多种类型**的代码，同时仍然保持编译期类型检查。

---
#### 1. 传统写法的问题

假设你想在一个 `int` 切片中查找元素的位置，你会写：
```go
func IndexInt(s []int, x int) int { ... }
```

如果还想在 `string` 切片中查找，就得再写一个几乎一模一样的函数：
```go
func IndexString(s []string, x string) int { ... }
```

逻辑完全相同，仅仅因为类型不同，代码被迫重复。所以我们把写函数类型的地方抽象出来

---
#### 2. 类型参数的解决方案

Go 1.18 引入了类型参数，使你可以**用一个函数同时支持多种类型**：
```go
func Index[T comparable](s []T, x T) int
```

`[T comparable]`：`T` 是**类型参数**（相当于“占位符”），`comparable` 是**约束**（限制 `T` 必须是可以使用 `==` 和 `!=` 进行比较的类型）。
`s []T`：第一个参数是元素类型为 `T` 的切片。
`x T`：第二个参数是待查找的值，类型与切片元素相同。
调用时，编译器会根据实际传入的参数自动推断 `T` 的具体类型（`int`、`string` 等），无需手动指定。

---
#### 3. `comparable` 约束

`comparable` 是 Go 内置的约束，它只允许那些支持 `==` 和 `!=` 比较的类型（如基本类型、指针、数组、结构体等，但不包括切片、map、函数）。
因为 `T` 满足 `comparable`，函数体内就可以安全地写 `v == x`。如果没有这个约束，编译会报错，因为并不是所有类型都能用 `==`。

---

#### 4. `Index` 函数逻辑

```go
func Index[T comparable](s []T, x T) int {
    for i, v := range s {
        if v == x {
            return i
        }
    }
    return -1
}

```

遍历切片 `s`，比较每个元素 `v` 和 `x`。
找到相等的就返回索引 `i`。
遍历完都没找到，返回 `-1`。

---

#### 5. `main` 中的使用

```go
si := []int{10, 20, 15, -10}
fmt.Println(Index(si, 15))   // 输出 2
ss := []string{"foo", "bar", "baz"}
fmt.Println(Index(ss, "hello")) // 输出 -1
```

第一次调用，`T` 被自动推断为 `int`，在 `int` 切片中查找 `15`，找到索引 `2`。
第二次调用，`T` 被推断为 `string`，查找 `"hello"`，没找到，返回 `-1`。
同一个函数，既可用于 `int` 切片，也可用于 `string` 切片，无需重写。

---

 **Go 泛型的核心思想：**
**类型参数** 让函数和类型可以处理多种数据类型，同时保留编译期类型安全。
**约束** 限制了类型参数必须支持的操作（比如 `comparable` 要求可比较）。
使用泛型可以避免为不同但相似的类型重复实现相同逻辑，代码更简洁、更通用。
这种写法在标准库和实际项目中越来越常见，例如 `slices.Index`、`maps.Keys` 等，都是基于泛型实现的。
