！？空的接口？！Empty interface！🥵

---
#### 定义
不指定任何方法的接口类型称为空接口：
```go
interface{}
```
空接口可以包含任何类型的值。（每种类型至少实现零个方法。）
空接口用于处理未知类型值的代码。例如， `fmt.Print` 可以接受任意数量的 `interface{}` 类型的参数。

---

空接口是 Go 语言中最特殊的接口，它和之前带方法的接口完全不同。
空接口没有定义任何方法，所以**任何类型都自动实现了空接口**（因为“实现零个方法”对任何类型来说都天然满足。）
空接口就像是一个**万能箱子**，什么类型的值都能往里装。

---
#### A Tour Of Go中的实例
此例源自A Tour Of Go——方法和接口——14/26——空的接口
```go
var i interface{}   // 声明一个空接口变量，初始为 nil 接口值
describe(i)         // (<nil>, <nil>)

i = 42              // 放入一个 int
describe(i)         // (42, int)

i = "hello"         // 放入一个 string
describe(i)         // (hello, string)

func describe(i interface{}) {
	fmt.Printf("(%v, %T)\n", i, i)
}
```
1.`i` 可以先后持有完全不同类型的值（`int`、`string`），因为它就是 `interface{}`。
2.`describe(i interface{})` 函数的参数类型也是空接口，所以可以接收任何类型的参数。
3.使用 `%v` 和 `%T` 分别打印**值**和**具体类型**。

---
####  空接口有什么用？

用来处理**类型不确定的值**。最典型的就是 `fmt.Println` 系列函数：
```go
func Println(a ...interface{}) (n int, err error)
```
它接受任意数量、任意类型的参数，就是因为参数是空接口切片。你可以写：
```go
fmt.Println(42, "hello", 3.14, true)
```
每种不同类型的值都能传进去，最终由 `fmt` 包内部根据实际类型做格式化。

---
#### 与带方法接口的对比

| 接口类型              | 方法要求                | 能持有哪些类型的值    |
| ----------------- | ------------------- | ------------ |
| 普通接口（如 `Abser`）   | 必须实现指定方法（如 `Abs()`） | 只有实现了这些方法的类型 |
| 空接口 `interface{}` | 无方法                 | **所有类型**     |

普通接口强调**行为**（你能做什么），空接口强调**任意值**（你是什么都行）。
