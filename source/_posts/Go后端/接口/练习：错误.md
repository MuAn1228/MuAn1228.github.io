复制[之前练习](https://go.dev/tour/flowcontrol/8)中的 `Sqrt` 函数，并对其进行修改，使其返回 `error` 值。 
当给定一个负数时， `Sqrt` 应该返回一个非 nil 的错误值，因为它不支持复数。
创建新类型
```go
type ErrNegativeSqrt float64
```

并因为给了它一个 `error` 而导致它出错

```go
func (e ErrNegativeSqrt) Error() string
```

方法使得 `ErrNegativeSqrt(-2).Error()` 返回 `"cannot Sqrt negative number: -2"` 。

**注意：** 在 `Error` 方法内部调用 `fmt.Sprint(e)` 会导致程序进入无限循环。您可以通过先将 `e` 转换为 float64 类型来避免这种情况： `fmt.Sprint(float64(e))` 。为什么呢？
修改 `Sqrt` 函数，使其在接收到负数时返回 `ErrNegativeSqrt` 值。

---

**这个练习是让你把之前写的平方根函数 `Sqrt` 改造成带错误处理版本，核心是自定义一个错误类型来表示“负数不能开平方”的情况。**

#### 练习要求拆解
##### 1. 修改 `Sqrt` 函数签名

原来的 `Sqrt(x float64) float64` 要改成：

```go
func Sqrt(x float64) (float64, error)
```

现在它返回两个值：一个 `float64` 的平方根结果，一个 `error`。成功时返回结果和 `nil`；失败时返回 0 和一个非 `nil` 的错误。

##### 2. 定义新错误类型 `ErrNegativeSqrt`

它底层是 `float64`，用于记录那个非法的负数：

```go
type ErrNegativeSqrt float64
```

然后给它实现 `error` 接口：

```go
func (e ErrNegativeSqrt) Error() string {
    // 返回类似 "cannot Sqrt negative number: -2" 的信息
}

```

##### 3. 在 `Sqrt` 中处理负数

如果 `x < 0`，直接返回 `0, ErrNegativeSqrt(x)`。

---

##### 代码框架解释

给出的框架：
```go
func Sqrt(x float64) (float64, error) {
    return 0, nil
}
func main() {
    fmt.Println(Sqrt(2))
    fmt.Println(Sqrt(-2))
}
```

现在 `Sqrt` 永远返回 0 和无错误，你需要把牛顿法求平方根的逻辑填进去，并加上负数判断。
`main` 分别调用正数和负数，你可以看到成功时打印结果，失败时打印错误。

---

### 重要警告：避免无限循环

教程特别提示：

> 在 `Error()` 方法里调用 `fmt.Sprint(e)` 会导致无限循环。应该先转换为 `float64(e)`。

**为什么？**  
因为 `e` 是 `ErrNegativeSqrt` 类型，它实现了 `error` 接口。如果你在 `Error()` 方法里写：

```go
func (e ErrNegativeSqrt) Error() string {
    return fmt.Sprint(e)   // 错误！
}
```

`fmt.Sprint(e)` 内部会检查 `e` 是否是 `error` 接口，发现它是，就会再次调用 `e.Error()`，形成无限递归，直到栈溢出。

正确做法是**把 `e` 转换成底层类型 `float64`**，让它成为一个普通数字，再打印：

```go
func (e ErrNegativeSqrt) Error() string {
    return fmt.Sprintf("cannot Sqrt negative number: %v", float64(e))
}
```

这里 `float64(e)` 就是那个负数，打印它不会再触发 `Error()` 方法。

##### 需要完成的任务

把 `ErrNegativeSqrt` 类型和它的 `Error()` 方法定义好。
在 `Sqrt` 函数中，如果 `x < 0`，返回 `0, ErrNegativeSqrt(x)`。
如果 `x >= 0`，用之前练习中牛顿法计算平方根，并返回 `result, nil`。


完成后，运行结果会类似：
```text
1.4142135623730951 <nil>
0 cannot Sqrt negative number: -2
```

因为 `fmt.Println` 打印 `error` 时会自动调用它的 `Error()` 方法。

---
#### 目标代码：
```go
package main

import (
    "fmt"
    "math"
)

type ErrNegativeSqrt float64

func (e ErrNegativeSqrt) Error() string {
    return fmt.Sprintf("cannot Sqrt negative number: %v", float64(e))
}

func Sqrt(x float64) (float64, error) {
    if x < 0 {
        return 0, ErrNegativeSqrt(x)
    }
    if x == 0 {
        return 0, nil
    }
    z := 1.0
    for {
        prevZ := z
        z -= (z*z - x) / (2 * z)
        if math.Abs(z-prevZ) < 1e-12 {
            break
        }
    }
    return z, nil
}

func main() {
    fmt.Println(Sqrt(2))
    fmt.Println(Sqrt(-2))
}
```
