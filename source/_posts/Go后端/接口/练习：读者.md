实现一个 `Reader` 类型，该类型发出无限的 ASCII 字符流。 `'A'` 。
给出的代码：
```go
package main

import "golang.org/x/tour/reader"

type MyReader struct{}

// TODO: Add a Read([]byte) (int, error) method to MyReader.

func main() {
	reader.Validate(MyReader{})
}

```

**正确的 `Read` 方法签名**
```go
func (m MyReader) Read(b []byte) (int, error)
```
它必须接收一个 `[]byte` 切片 `b`（缓冲区）
返回两个值：实际写入的字节数 `n` 和可能的错误 `err`
你的任务是用字符 `'A'` 填满整个缓冲区，并返回 `len(b), nil`

**无限流意味着永远不返回 `io.EOF`**
普通的 `Reader` 在读完数据后会返回 `io.EOF`，但本题要求**无限流**，所以你永远不返回 `EOF`，每次调用都返回 `len(b)` 和 `nil`。

---

目标代码：
```go
package main

import "golang.org/x/tour/reader"

type MyReader struct{}

// TODO: Add a Read([]byte) (int, error) method to MyReader.
func (m MyReader) Read(b []byte) (int, error) {
    for i := range b {
        b[i] = 'A'
    }
    return len(b), nil
}

func main() {
	reader.Validate(MyReader{})
}

```
