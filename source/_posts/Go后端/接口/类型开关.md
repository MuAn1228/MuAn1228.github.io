#### 定义
类型开关是一种允许连续进行多个类型断言的结构。
类型开关就像普通的 switch 语句，但类型开关中的 case 指定类型（而不是值），并将这些值与给定接口值所持有的值的类型进行比较。
```go
switch v := i.(type) {
case T:
    // here v has type T
case S:
    // here v has type S
default:
    // no match; here v has the same type as i
}
```
类型切换中的声明与类型断言 `i.(T)` 语法相同，但具体类型 `T` 被关键字 `type` 替换。

`i` 是一个接口变量（比如 `interface{}`）。
`i.(type)` 是**关键字 `type`**，不是某个具体的类型。它告诉编译器：“我要根据 `i` 当前的实际类型来匹配”。
每个 `case` 后面跟的**不是一个值，而是一种类型**（如 `int`、`string`、`*Vertex` 等）。
 匹配成功后，`v` 就会变成那个具体的类型，并且可以直接使用该类型特有的方法。

此 switch 语句测试接口值 `i` 是否包含类型为 `T` 或 `S` 的值。在 `T` 和 `S` 两种情况下，变量 `v` 都将是类型为 T 或 S 的值。 分别对应 `T` 或 `S` ，并保存 `i` 所保存的值。在默认情况下（没有匹配项），变量 `v` 与 `i` 具有相同的接口类型和值。

---

简单来说，switches使得你能够进行多次类型断言。它是 Go 语言里**把多个类型断言写得更清晰、更紧凑**的一种语法结构。之前学到的类型断言一次只能检查一种类型，如果可能的类型很多，用if-else if写就会很啰嗦。类型开关就是专门用来简化这种场景的。

#### 类型开关的优点：
1.**一次检查多种类型**，代码比一堆 `if-else` 更清晰。
2.**自动在每个 case 里将变量转换为匹配的具体类型**，你不再需要手动进行类型断言。
3.**保持安全**，像类型断言的安全形式一样，如果类型不匹配，只会走到 `default`，不会 panic。

#### A Tour Of Go中的实例
此例源自A Tour Of Go——方法和接口——16/26——类型开关
```go
package main

import "fmt"

func do(i interface{}) {
	switch v := i.(type) {
	case int:
		fmt.Printf("Twice %v is %v\n", v, v*2)
	case string:
		fmt.Printf("%q is %v bytes long\n", v, len(v))
	default:
		fmt.Printf("I don't know about type %T!\n", v)
	}
}

func main() {
	do(21)
	do("hello")
	do(true)
}

```
不难推出程序输出为：
```text
Twice 21 is 42
"hello" is 5 bytes long
I don't know about type bool!
```
