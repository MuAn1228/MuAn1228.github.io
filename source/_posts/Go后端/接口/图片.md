[包 image](https://go.dev/pkg/image/#Image) 定义了 `Image` 接口：
```go
package image

type Image interface {
    ColorModel() color.Model
    Bounds() Rectangle
    At(x, y int) color.Color
}
``` 

**注意** ： `Bounds` 方法的 `Rectangle` 返回值实际上是一个 [`image.Rectangle`](https://go.dev/pkg/image/#Rectangle) ，因为声明在 `image` 包内。
（详情请参阅相关[文档](https://go.dev/pkg/image/#Image) 。）
`color.Color` 和 `color.Model` 类型也是接口，但我们将忽略这一点，而使用预定义的实现 `color.RGBA` 和 `color.RGBAModel` 。这些接口和类型由 [image/color 包](https://go.dev/pkg/image/color/)指定。

---

```go
package main

import (
	"fmt"
	"image"
)

func main() {
	m := image.NewRGBA(image.Rect(0, 0, 100, 100))
	fmt.Println(m.Bounds())
	fmt.Println(m.At(0, 0).RGBA())
}

```

1.image.Image 接口
```go
type Image interface {
    ColorModel() color.Model
    Bounds() Rectangle
    At(x, y int) color.Color
}
```

它规定了任意图像必须提供的三个能力：
**`ColorModel()`**：返回图像使用的颜色模型（如 RGB、灰度等）。
**`Bounds()`**：返回图像的矩形边界，即图像的宽高范围。
**`At(x, y)`**：返回 `(x, y)` 位置像素的颜色值。

任何具体类型只要实现了这三个方法，就可以当作图像使用。

---

2.示例代码解读
```go
m := image.NewRGBA(image.Rect(0, 0, 100, 100))
fmt.Println(m.Bounds())
fmt.Println(m.At(0, 0).RGBA())
```
`image.NewRGBA(...)` 创建了一个 **RGBA 类型** 的图像（每个像素由红、绿、蓝、透明度四个分量组成），尺寸为 100×100 像素。
`m.Bounds()` 返回图像的边界矩形，输出 `(0,0)-(100,100)`。
`m.At(0, 0)` 获取左上角像素的颜色，返回一个 `color.Color` 接口值。
调用 `.RGBA()` 将该颜色转换为 **RGBA 四个 16 位分量**（每个分量范围 0-65535），输出类似 `0 0 0 0`（初始黑色透明）。

---

3.与接口知识的关系
`image.Image` 是接口，`*image.RGBA` 是具体实现（就像 `io.Reader` 与 `*strings.Reader` 的关系）。
`color.Color` 也是接口，而 `color.RGBA` 等类型实现了它，所以 `At` 可以返回任意颜色表示。
标准库通过这种接口设计，让你可以用统一的方式操作各种图像格式（PNG、JPEG、内存图像等），而无需关心底层细节。
